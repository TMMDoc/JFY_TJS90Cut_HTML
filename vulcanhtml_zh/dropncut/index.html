Drop and Cut

Drop and Cut

Drop and Cut 功能使用安装在机器内部的网络摄像头，提供托盘上板材的实时视图。校准摄像头后，您可以在后处理中将零件直接放置到摄像头图像上，Vulcan 会自动捕获工件偏移——无需手动输入偏移量。

在机器内安装摄像头

摄像头安装在机器内部，位于门的内侧右上方，距离为 50 mm。它从机器内部提供视角。视角经过倾斜调整，以对准半张板材的放置位置。

在 Vulcan 中连接网络摄像头

要建立摄像头与 Vulcan 之间的通信，必须将摄像头的 IP 地址配置为与机器 IP 地址在同一网段内。

检查机器 IP 地址

  1. 切换到 Service User Active 模式：

    1. 打开 Settings

    2. 选择 Switch User

    3. 将用户组更改为 Service User Active

  2. 打开 Command Shell：

    1. 进入 Windows Tools

    2. 选择 Command Shell

  3. 输入 ipconfig 并按 Enter。系统将显示机器的网络详细信息，包括局域网中连接的 IP 地址。

配置摄像头 IP 地址

摄像头的 IP 地址必须配置为与机器在同一网段。

示例：

  • 机器 IP：192.168.1.176

  • 摄像头 IP：192.168.1.xxx

请确保摄像头 IP 地址是唯一的，未被分配给其他设备。请联系 IT 团队确认唯一性。
默认情况下，Hikvision DS-2CD1027G2-L 摄像头使用 IP 192.168.1.64，该地址已在正确的网段内。除非 IP 地址不同，否则无需手动配置。

配置系统 IP 地址（如有需要）

如果摄像头具有不同的 IP 地址：

  1. 通过以太网将摄像头直接连接到系统。

  2. 使用摄像头手册中提供的默认 IP 地址。

  3. 将系统 IP 配置为同一网段：

    • IP 地址： 192.168.1.176

    • 子网掩码： 255.255.255.0

    • 默认网关： 根据需要设置

请确保系统 IP 地址与摄像头 IP 地址在同一网段内。请勿分配网络中已被其他设备使用的 IP 地址。

在 Vulcan 中配置摄像头

  1. 导航到 C:\ProgramData\Metamation\Vulcan\Data 并使用文本编辑器打开 CamSettings.xml。

  2. 更新配置详细信息：

    <Camera id="1" description="Camera 1" enable="true">
  <Configuration>
    <LiveStream enable="false"
      url="http://192.168.1.64/ISAPI/Streaming/channels/101/picture" />
    <LiveStreamDefault enable="true"
      url="http://192.168.1.64/ISAPI/Streaming/channels/101/picture" />
    <Authentification username="admin" password="your_password" />
  </Configuration>
</Camera>

  3. 将 url 字段中的 IP 地址替换为实际的摄像头 IP。

  4. 如有需要，更新身份验证信息。

  5. 保存文件并关闭编辑器。

验证摄像头连接

  1. 打开 Vulcan → Calibration 页面。

  2. 确认摄像头画面正确显示。

  3. 确保：

    • 摄像头 IP 与 XML 配置一致

    • 系统与摄像头在同一网段内

    • 用户名和密码正确

校正摄像头畸变

Vulcan 目前不支持摄像头去畸变功能。该功能将在未来版本中实现。Vulcan 支持所有 IP 摄像头，但使用存在畸变的摄像头可能会有一些偏差。

要校正镜头畸变：

  1. 打印棋盘格图案并将其粘贴在平整、坚硬的黑板上。确保表面平整，不会弯曲。

  2. 拍摄棋盘格的多张图像。拍摄时：

    • 移动黑板，使棋盘格的不同部分出现在摄像头视野的中心、边缘和角落位置。

    • 以略有不同的角度倾斜黑板，以捕获更多变化。

      这有助于校准过程理解摄像头在整个视野范围内的成像特性。

运行去畸变功能

将拍摄的图像通过去畸变代码进行处理。代码将计算：

  • K（内参矩阵） — 表示摄像头的焦距和光学中心

  • 畸变系数 — 表示摄像头中存在的镜头畸变

这些值描述了摄像头如何成像以及如何产生畸变。所有矩阵都可以保存为 XML 格式，并在之后重复使用，前提是摄像头设置保持不变（未移动、未改变焦距等）。

验证去畸变效果

  • 去畸变完成后，检查畸变是否已被正确校正，输出图像是否准确。

  • 镜头畸变通常在图像的边缘和角落区域更为明显，因此请特别关注这些区域。

  • 如果畸变未被正确校正，请使用质量更好的图像重新进行去畸变处理。

校准步骤

  1. 进入 Configure → Calibration。

    ① 显示位置指示激光的实时坐标。
    ② 引导用户完成校准过程的状态消息。
    ③ 显示已保存的边界区域。
    ④ 捕获新的边界区域。

  2. 摄像头的实时图像将显示在控制屏幕上。

  3. 单击 Show Bound 查看已保存的校准边界。这有助于验证可见区域并确认摄像头是否正确定位以捕获所需的板材区域。

  4. 如果显示的边界与所需的板材区域不匹配，请单击 Capture 重置并提供新的边界点。

  5. 通过逐一测量板材上的四个参考点来进行校准，引导位置指示激光并单击该位置，从而形成精确的矩形边界。

捕获模式

① 引导捕获点的顺序。
② 退出捕获模式且不保存更改。

将位置指示激光放置在所需位置并单击该点后，系统将自动捕获相应点的位置指示激光坐标。

如果在校准页面移动激光头时位置指示激光点未更新，文本框将提示用户手动输入机器坐标，必须手动输入并按 Enter 或单击文本框外部进行确认。

输入所有四个点后，将出现确认弹窗。如果确认，边界将被添加；如果取消，将保留之前的边界。确认后，边界将被显示。

校准是一次性过程，除非摄像头位置或托盘发生更改，否则始终有效。

在后处理中使用校准视图

  1. 保存边界后，通过从 Programs 中选择所需的 LST 文件进入 Postproduction。

  2. 后处理中的摄像头视图使用已保存的边界，在此范围内可以添加和保存零件。

  3. 单击 Save NC — 工件偏移将相对于边界区域被捕获。保存的零件随后可以直接切割，无需手动捕获工件偏移。
