程序头

程序头是程序的开始部分，在程序运行期间只执行一次，由以下部分组成：

  • 程序号

  • 程序名（作为注释）

  • 控制器 ID（串联操作）

  • 程序规格

  • XY 程序限位

  • 程序尺寸标注

  • 双头同步（串联操作）

  • 检查工件偏移与特殊功能

  • 激活 G17（XY 平面）并带板材旋转

结构：

%1 (Sample.DIN)

程序号和程序名（作为注释）

CNC ID

控制器 ID（1 或 2）

Sheet_Size_X

程序规格

Sheet_Size_Y

Job_Size_X

Job_Size_Y

X_Limit_Minus

XY 程序限位

X_Limit_Plus

Y_Limit_Minus

Y_Limit_Plus

G90

程序尺寸标注（绝对）

M50

双头同步

M15

检查工件偏移与特殊功能

G17 D=SheetRotation

XY 平面相对于板材旋转

程序号

程序号始终赋值为 %1。因为所有激光技术程序都作为子程序分配，并使用编号 1 从主程序调用。因此，确保程序号的正确性非常重要。

  • 程序号必须始终为 %1

程序名

程序名在程序中作为注释定义，将用于程序块搜索功能。根据名称，PLC 将保存程序的当前程序块号、坐标等信息，再次加载时，相应的值将从 PLC 中检索。

  • 程序名必须在注释中

CNC ID

对于双头串联操作，将为单个作业生成 2 个程序，CNC ID 将指定在控制器中加载哪个程序，如下所示：

  1. CNC_ID = 1，将包含程序的前半部分，并加载到 X 轴机器原点起始处的控制器中。

  2. CNC_ID = 2，将包含程序的后半部分，并加载到 X 轴机器正向行程极限处的控制器中。

这些值被分配给 P 字段，为了便于理解，P 字段在程序中 内部全局声明，如下所示：

#globdef CNC_ID P1909

  • CNC_ID 仅在双头串联操作时需要

程序规格

程序规格定义了沿 X 和 Y 轴的板材尺寸和作业尺寸。根据机器原点的位置，尺寸中需要标注正号或负号。

  • 左下 = X+，Y+

  • 右下 = X+，Y-

  • 左上 = X-，Y+

  • 右上 = X- Y-

这些值被分配给 P 字段，为了便于理解，P 字段在程序中 内部全局声明，如下所示：

#globdef Sheet_Size_X P1900

#globdef Sheet_Size_Y P1901

#globdef Job_Size_X P1902

#globdef Job_Size_Y P1903

  • 此信息将用于废料切割和边界检查程序。

XY 程序限位

X 和 Y 轴程序限位的定义是为了确保机器行程在限制范围内。它们在双头串联操作中最为有用，在该操作中，单个作业被分配给 2 个头，其限位定义用于安全、边界检查程序和自动润滑程序。

这些值被分配给 P 字段，为了便于理解，P 字段在程序中 内部全局声明，如下所示：

#globdef X_Limit_Minus P1910

#globdef X_Limit_Plus P1911

#globdef Y_Limit_Minus P1912

#globdef Y_Limit_Plus P1913

  • 此信息在双头串联操作中更为有用

程序尺寸标注

程序尺寸标注定义程序中轴的尺寸是绝对的还是增量的。

语法：     G90/G91

双头同步

如果有双头串联操作，则"M50"命令将在两个控制器之间进行同步，并检查程序名、工件偏移等，然后继续进行切割。

语法：     M50

  • M50 命令仅用于串联操作，否则不需要

检查工件偏移和特殊功能

程序中的第一个 M15 命令将检查以下内容：

  1. 根据捕获的工件偏移和作业尺寸，计算程序中 X 和 Y 轴的最大行程限位，然后与其终端限位进行交叉检查。如果行程在限制范围内，则继续执行，否则程序将终止。

  2. 检查在切割开始前是否有任何特殊子程序功能（如喷嘴清洁、自动润滑等）处于激活状态。通常，在正常切割期间，如果任何特殊功能处于激活状态，它们将等待 M15 命令，此时刀具将抬起。

    语法：     M15

激活 G17（XY 平面）并带板材旋转

激活 XY 平面并设置相对于板材的旋转角度，使程序在切割时也随之旋转，并且作业适配在旋转后的板材内。

语法：     G17 D=SheetRotation

  • 板材旋转角度由边缘检测功能计算得出

程序头示例：

%1 (PP_Sample_Pgm.DIN)
CNC_ID=1（仅用于串联操作）
Sheet_Size_X = 120
Sheet_Size_Y = 600
Job_Size_X = 105
Job_Size_Y = 573
X_Limit_Minus = 10
X_Limit_Plus = 115
Y_Limit_Minus = 10
Y_Limit_Plus = 583
G90
M50（仅用于串联操作）
M15
G17 D=SheetRotation
