回退高度

TC_POS_LEVEL

定义

修改回退高度。

当使用 TC_LASER_OFF(1) 或 (3) 关闭激光束时，切割头移动到板材表面加回退高度的位置。

编程

TC_POS_LEVEL (回退高度)

  • 自保持（模态）操作。

  • 在 TC_LASER_OFF(1) 或 (3) 时生效。

  • 如果未编程 TC_POS_LEVEL，Z 轴将逼近标准值

参数
参数 输入

最小回退高度

0

控制系统将最小回退高度限制为当前切割高度。

最大回退高度

基本设置（参见机器数据集）

在最小值和最大值之间，可以按 0.1 mm 或 0.004 英寸的步长编程任意回退高度。

TC_POS_LEVEL_FIX

定义

TC_POS_LEVEL_FIX 循环以跨程序方式定义切割头在越过时回退的距离。回退高度

当使用 TC_LASER_OFF(1) 或 (3) 关闭激光束时，切割头移动到板材表面加回退高度的位置。

编程

TC_POS_LEVEL_FIX(回退高度)

  • 自保持（模态）操作。

  • 在 TC_LASER_OFF(1) 或 (3) 时生效。

  • 覆盖 TC_POS_LEVEL。

  • 如果未编程 TC_POS_LEVEL_FIX，Z 轴在 TC_LASER_OFF(1) 时逼近由 TC_POS_LEVEL 定义的值。

参数描述
参数 输入

最小回退高度

0

控制系统将最小回退高度限制为当前切割高度。

最大回退高度

基本设置（参见机器数据集）

在最小值和最大值之间，可以按 0.1 mm 或 0.004 英寸的步长编程任意回退高度。
