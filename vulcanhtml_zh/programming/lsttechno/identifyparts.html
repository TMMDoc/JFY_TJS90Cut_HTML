零件标识

TC_WRITE

定义

可以使用 TC_WRITE 循环在工件上雕刻可变文本。

TC_WRITE 循环在当前位置沿正 X 方向输出文本。可以通过循环的相应传递参数更改激光技术表、字体高度（毫米）和文本方向（度）。

对于圆管应选择平面加工。
编程

TC_WRITE(T_TEXT,T_TABNAME,T_HEIGHT,T_ANGLE)

  • TC_WRITE 必须在轮廓加工（TC_LASER_ON）之前编程。

传递参数
参数 值 定义

T_TEXT

-

要雕刻在工件上的文本（最多 255 个字符）。

T_TABNAME

-

激光技术表的名称。

T_HEIGHT

-

字体大小（毫米或英寸）。

T_ANGLE

默认值：0°

文本旋转角度的可选参数（度）。
示例

TC_WRITE("Teil Nr. 17","TTBC-8252O2",5,0)

使用变量计数零件

int actNumber = 13
TC_WRITE("Part No.: "<< actNumber,"TTBC-8252O2",10,0)

特殊宏

以下宏存储在机器中。它们允许输出生产信息（工件生产的日期和/或时间）：

宏 示例

雕刻带有程序后缀 *MPF 的当前主程序名称。

TM_MAINPROG

TC_WRITE(TM_MAINPROG,"TTBC-8252O2",10,0)

雕刻当前主程序名称。

TM_MAINPROG_SHORT

TC_WRITE(TM_MAINPROG_SHORT,"TTBC-8252O2",10,0)

雕刻当前时间。格式：hh:mm:ss。

TM_TIME

TC_WRITE(TM_TIME,"TTBC-8252O2",10,0)

雕刻当前日期。公制格式：dd.mm.yyyy / 英制格式：mm/dd/yyyy

TM_DATE

公制编程：
TC_WRITE(TM_DATE,"TTBC-8252O2",10,0)
英制编程：
TC_WRITE(TM_DATE,"TTBC-8252O2",0.393,0)

雕刻时间和当前日期（格式取决于计量单位）。

TM_TIMEDATE

公制编程：
TC_WRITE(TM_TIMEDATE,"TTBC-8252O2",5,0)
英制编程：
TC_WRITE(TM_TIMEDATE,"TTBC-8252O2",0.197,0)

雕刻机器名称。

TM_MACHINE_NUMBER

TC_WRITE(TM_MACHINE_NUMBER,"TTBC-8252O2",0.197,0)

TC_LABEL

此功能适用于配备 SINUMERIK ONE 控制器的 TruLaser Series 5000 和 TruLaser Series 3000 的 2D 激光机。
定义

TC_LABEL 循环可用于使用以下标签标识工件： * 数据矩阵码。 * 纯文本。

编程

TC_LABEL

  • LabelGroup ID：来自 PARTS_IN_PROGRAM_POS 表的参数 ID 10（零件的连续编号）。

  • TC_LABEL 在主程序中。

LABEL_DATA 技术表参数
ID 参数 值 单位 描述

10

LabelGroupID

-

-

每个不同的标签都有一个编号（LabelGroupID）。LABEL_DATA 表的一个数据记录包含一个标签的参数。
如果要在一个零件上应用多个标签，则一个 LabelGroupID 有多个数据记录。
如果要在多个零件上应用一个标签，则在多个 PARTS_IN_PROGRAM_POS 数据记录中调用相同的 LabelGroupID。

1

-

第一个标签的编号。

n

-

第 n 个标签的编号。

20

Sequence

1 - n

-

指示标签应用到零件上的顺序（如果一个 LabelGroupID 有多个数据记录）。

30

Offset X position

mm

指示标签包围矩形左下角的 X 位置，相对于零件坐标系（PARTS_IN_PROGRAM_POS）中零件的重心。

40

Offset Y position

mm

指示标签包围矩形左下角的 Y 位置，相对于零件坐标系（PARTS_IN_PROGRAM_POS）中零件的重心。

°

mm

Label type

标识类型。
