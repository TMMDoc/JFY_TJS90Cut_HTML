零件计时

TC_TIMER

定义

使用 TC_TIMER 循环，可以测量、显示和记录单个工件的加工时间。最多可以同时编程五个计时，并在之后一起显示。

编程

TC_TIMER (INT P1, INT NUMBER, STRING[20] COMMENT)

  • 激光束不得点燃。

  • 最多可以并行或依次启动五个计时。顺序可以任意。

  • 启动每个计时需要 0.5 秒。如果同时启动多个计时，则每个计时都会增加这 0.5 秒。

  • 最大可测量时间为九小时。

参数
参数 值 定义

INT P1

1

启动计时。

2

停止计时并保存。同时，加工程序继续运行。

3

停止所有计时并显示。加工程序将停止，直到显示关闭。

4

停止所有计时并记录。同时，加工程序继续运行。

INT NUMBER

1 - 5

测量编号。

STRING[20] COMMENT

-

注释，不超过 20 个字符。
计时日志

使用 TC_TIMER(4)，循环将测量结果写入日志 'tc_timer.txt'。

日志写入目录 'c:\dh\topsmanu.dir\log \tc_timer'，并格式化以便通过表格计算进行评估。可以使用"编程"下"附加功能"中的 TC_TIMER Logs 按钮查看和导出日志。

  • 文件最大大小为 100 kByte。

  • 达到最大文件大小后，文件开头 20% 的数据（最旧的条目）将被删除。

  • 文件可以完全删除。下次测量时将自动重新创建。

日志条目 定义

PROGRAMM

主程序名称

DATE

日志条目的日期和时间

TIMERNR

计时器编号，传递参数 INT_NUMBER

VALUE

测量时间，格式为 HH:MM:SS。

COMMENT

注释，传递参数 STRING[20] COMMENT
