Zeitmessung von Teilen

TC_TIMER

Definition

Mit dem Zyklus TC_TIMER können Bearbeitungszeiten für einzelne Werkstücke gemessen, angezeigt und protokolliert werden. Es können maximal fünf Zeitmessungen gleichzeitig programmiert und anschließend gemeinsam angezeigt werden.

Programmierung

TC_TIMER (INT P1, INT NUMBER, STRING[20] COMMENT)

  • Der Laserstrahl darf nicht gezündet sein.

  • Es können maximal fünf Zeitmessungen parallel oder nacheinander gestartet werden. Die Reihenfolge ist beliebig.

  • Der Start jeder Zeitmessung dauert 0,5 Sekunden. Werden mehrere Zeitmessungen gleichzeitig gestartet, werden diese 0,5 Sekunden zu jeder Zeitmessung addiert.

  • Die maximal messbare Zeit beträgt neun Stunden.

Parameter
Parameter Wert Definition

INT P1

1

Zeitmessung starten.

2

Zeitmessung stoppen und speichern. Gleichzeitig läuft das Bearbeitungsprogramm weiter.

3

Alle Zeitmessungen stoppen und anzeigen. Das Bearbeitungsprogramm wird angehalten, bis die Anzeige geschlossen wird.

4

Alle Zeitmessungen stoppen und protokollieren. Gleichzeitig läuft das Bearbeitungsprogramm weiter.

INT NUMBER

1 - 5

Nummer der Messung.

STRING[20] COMMENT

-

Kommentar, maximal 20 Zeichen.
Zeitmessungsprotokoll

Mit TC_TIMER(4) schreibt der Zyklus das Ergebnis der Messungen in das Protokoll 'tc_timer.txt'.

Das Protokoll wird in das Verzeichnis 'c:\dh\topsmanu.dir\log \tc_timer' geschrieben und ist für die Auswertung über eine Tabellenkalkulation formatiert. Das Protokoll kann über die Schaltfläche TC_TIMER-Protokolle unter Programmierung, Zusatzfunktionen, angezeigt und exportiert werden.

  • Die maximale Dateigröße beträgt 100 kByte.

  • Ist die maximale Dateigröße erreicht, werden 20 % der Daten am Anfang der Datei (die ältesten Einträge) gelöscht.

  • Die Datei kann vollständig gelöscht werden. Sie wird dann bei der nächsten Messung automatisch neu erstellt.

Protokolleintrag Definition

PROGRAMM

Name des Hauptprogramms

DATE

Datum und Uhrzeit des Protokolleintrags

TIMERNR

Nummer des Timers, Übergabeparameter INT_NUMBER

VALUE

Gemessene Zeit in HH:MM:SS.

COMMENT

Kommentar, Übergabeparameter STRING[20] COMMENT
