Teile kennzeichnen

TC_WRITE

Definition

Mit dem Zyklus TC_WRITE kann variabler Text auf dem Werkstück eingraviert werden.

Der Zyklus TC_WRITE gibt den Text an der aktuellen Position in positiver X-Richtung aus. Die Lasertechnologietabelle, die Schrifthöhe in mm und die Textrichtung in Grad können über die entsprechenden Übergabeparameter des Zyklus geändert werden.

Für Rundrohre sollte die Planbearbeitung gewählt werden.
Programmierung

TC_WRITE(T_TEXT,T_TABNAME,T_HEIGHT,T_ANGLE)

  • TC_WRITE muss vor der Konturbearbeitung (TC_LASER_ON) programmiert werden.

Übergabeparameter
Parameter Wert Definition

T_TEXT

-

Text, der auf dem Werkstück eingraviert werden soll (max. 255 Zeichen).

T_TABNAME

-

Name der Lasertechnologietabelle.

T_HEIGHT

-

Schriftgröße in mm oder Zoll.

T_ANGLE

Standardwert: 0°

Optionaler Parameter für Textdrehung in Grad.
Beispiel

TC_WRITE("Teil Nr. 17","TTBC-8252O2",5,0)

Teile zählen mit einer Variablen

int actNumber = 13
TC_WRITE("Part No.: "<< actNumber,"TTBC-8252O2",10,0)

Spezielle Makros

Die folgenden Makros sind an der Maschine hinterlegt. Sie ermöglichen die Ausgabe von Produktionsinformationen (Datum und/oder Uhrzeit der Herstellung eines Werkstücks):

Makro Beispiel

Name des aktuellen Hauptprogramms mit Programmsuffix *MPF eingravieren.

TM_MAINPROG

TC_WRITE(TM_MAINPROG,"TTBC-8252O2",10,0)

Name des aktuellen Hauptprogramms eingravieren.

TM_MAINPROG_SHORT

TC_WRITE(TM_MAINPROG_SHORT,"TTBC-8252O2",10,0)

Aktuelle Uhrzeit eingravieren. Format: hh:mm:ss.

TM_TIME

TC_WRITE(TM_TIME,"TTBC-8252O2",10,0)

Aktuelles Datum eingravieren. Metrisches Format: TT.MM.JJJJ / Zollformat: MM/TT/JJJJ

TM_DATE

Metrische Programmierung:
TC_WRITE(TM_DATE,"TTBC-8252O2",10,0)
Zoll-Programmierung:
TC_WRITE(TM_DATE,"TTBC-8252O2",0.393,0)

Uhrzeit und aktuelles Datum eingravieren (Formatierung hängt von der Maßeinheit ab).

TM_TIMEDATE

Metrische Programmierung:
TC_WRITE(TM_TIMEDATE,"TTBC-8252O2",5,0)
Zoll-Programmierung:
TC_WRITE(TM_TIMEDATE,"TTBC-8252O2",0.197,0)

Name der Maschine eingravieren.

TM_MACHINE_NUMBER

TC_WRITE(TM_MACHINE_NUMBER,"TTBC-8252O2",0.197,0)

TC_LABEL

Diese Funktion ist für 2D-Lasermaschinen der TruLaser Serie 5000 und TruLaser Serie 3000 mit der Steuerung SINUMERIK ONE verfügbar.
Definition

Mit dem Zyklus TC_LABEL können Werkstücke mit folgenden Beschriftungen gekennzeichnet werden: * Data Matrix Code. * Klartext.

Programmierung

TC_LABEL

  • LabelGroup ID: Parameter-ID 10 (laufende Nummer des Teils) aus der Tabelle PARTS_IN_PROGRAM_POS.

  • TC_LABEL steht im Hauptprogramm.

Parameter der Technologietabelle LABEL_DATA
ID Parameter Wert Einheit Beschreibung

10

LabelGroupID

-

-

Jede unterschiedliche Beschriftung hat eine Nummer (LabelGroupID). Ein Datensatz für die Tabelle LABEL_DATA enthält die Parameter für eine Beschriftung.
Sollen mehrere Beschriftungen auf ein Teil aufgebracht werden, gibt es mehrere Datensätze für eine LabelGroupID.
Soll eine Beschriftung auf mehrere Teile aufgebracht werden, wird dieselbe LabelGroupID in mehreren PARTS_IN_PROGRAM_POS-Datensätzen aufgerufen.

1

-

Nummer der ersten Beschriftung.

n

-

Nummer der n-ten Beschriftung.

20

Sequence

1 - n

-

Gibt die Reihenfolge an, in der die Beschriftungen auf das Teil aufgebracht werden sollen (bei mehreren Datensätzen für eine LabelGroupID).

30

Offset X-Position

mm

Gibt die X-Position der linken unteren Ecke des umschreibenden Rechtecks der Beschriftung relativ zum Schwerpunkt des Teils im Teilekoordinatensystem (PARTS_IN_PROGRAM_POS) an.

40

Offset Y-Position

mm

Gibt die Y-Position der linken unteren Ecke des umschreibenden Rechtecks der Beschriftung relativ zum Schwerpunkt des Teils im Teilekoordinatensystem (PARTS_IN_PROGRAM_POS) an.

50

Offset-Winkel

°

Gibt die Winkellage der Beschriftung relativ zum Teilekoordinatensystem (PARTS_IN_PROGRAM_POS) an, bezogen auf die linke untere Ecke des umschreibenden Rechtecks der Beschriftung.

60

Beschriftungstext

-

-

Text, der auf die Teilekopie gedruckt werden soll.

70

Beschriftungsfeldlänge X

mm

Maximale Ausdehnung der Beschriftung in X-Richtung im Beschriftungskoordinatensystem.

80

Beschriftungsfeldlänge Y

mm

Maximale Ausdehnung der Beschriftung in Y-Richtung im Beschriftungskoordinatensystem.

90

Beschriftungstyp

Art der Kennzeichnung.

3

-

Text (Beschriftungstext ist Base64-codiert).

4

-

Data Matrix Code (Beschriftungstext ist Base64-codiert).

110

Texthöhe

mm

Höhe des vorgeschlagenen Textes. Angegeben wird die Versalhöhe (Höhe der Großbuchstaben).
