Änderung

Produktionsplan sperren/entsperren

Diese Funktion dient zum Sperren/Entsperren von Produktionsplanpaketen.

  • Nach dem Importieren eines Produktionsplanpakets ist es standardmäßig gesperrt.

  • Wählen Sie einen Produktionsplan aus und klicken Sie auf die Sperr-Schaltfläche, um den Produktionsplan zu entsperren. Das bedeutet, dieser Produktionsplan ist nun ein aktiver Produktionsplan.

  • Sobald das Produktionsplanpaket aktiv ist, müssen alle enthaltenen Programme geladen werden (wie bei aktuellem Klick auf "Ausführen"), damit die allgemeinen Informationen gelesen und Vorschauzeichnungen angezeigt werden.

  • Sperren/Entsperren wirkt sich auf den gesamten Produktionsplan aus. Es ist nicht möglich, dies für ein einzelnes Programm einzustellen. (In der Anfangsphase ist keine Reihenfolgenanpassung möglich, daher ist dieser Zugriff für einzelne Programme gesperrt.)

  • Es können mehrere Produktionsplanpakete gleichzeitig importiert und entsperrt werden. Jedoch wird nur das aktuell laufende Programm in dunkler Farbe hervorgehoben.

  • Ein aktiver Produktionsplan kann nicht sofort gelöscht werden. Für andere Operationen muss der Produktionsplan zuerst gesperrt werden.

  • Es gibt eine Variable, die den aktiven/inaktiven Zustand des Produktionsplans anzeigt. Wenn die Hauptseite auf eine andere Seite gewechselt wird (nicht im Produktionsplan ausführen), wird die Variable auf False gesetzt, und wenn die Seite zum Produktionsplan zurückkehrt, wird die Variable wieder auf den vorherigen Zustand gesetzt.

  • Wenn die Maschine neu gestartet wird, sollte der Produktionsplanzustand beibehalten werden. Beim Aufrufen der Produktionsplanseite ist der zuvor aktive Produktionsplan weiterhin aktiv.

Reihenfolgenanpassung

Diese Funktion dient zur Anpassung der Priorität von Produktionsplanpaketen in der Produktionsplanliste, wodurch die Bearbeitungsreihenfolge geändert wird.

  • Wählen Sie einen Produktionsplan aus und verwenden Sie die Auf/Ab-Symbole, um die Reihenfolge anzupassen.

  • Der obere hat die höhere Priorität.

  • Jeder entsperrte Produktionsplan wird der Reihe nach von oben nach unten abgearbeitet. (In der Anfangsphase kann nur ein Produktionsplan bearbeitet werden; die automatisierte Abarbeitung nacheinander könnte in Zukunft umgesetzt werden.)

Produktionsplan löschen

Diese Funktion dient zum Löschen von Produktionsplanpaketen aus der Produktionsplanliste.

  • Wählen Sie einen Produktionsplan aus und verwenden Sie das "X"-Symbol, um das Produktionsplanpaket zu löschen.

  • Das gesamte ausgewählte Paket wird gelöscht. Es ist nicht möglich, ein einzelnes Programm einzeln zu löschen.

  • Es wird nur der Produktionsplan aus der Produktionsplanliste entfernt, die aufgeteilten Programme auf der ursprünglichen Programmseite werden nicht gelöscht. So kann der Bediener die Programme weiterhin für Einzelaufträge verwenden.
