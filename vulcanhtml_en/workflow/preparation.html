Preparation

Switching the machine ON

Unlocking the EMERGENCY STOP pushbutton

EMERGENCY STOP push buttons are located on the operating panel of the laser processing machine and on the safety post of the pallet changer.

To release the EMERGENCY STOP push-button, press it in and turn it in clockwise direction.

Close the door

The machine could only be started when the door switch is locked in. If the door button is not turning into steady illumination please check the alignment of the door switch.

Switch ON the drives

Use the drive enable key.

Homing the Axis

When the machine is switched ON, the axes must be homed. This is done by pressing the HOME → Automatic key in the HMI interface. The axes are then moved to the reference point.

Switch on the laser

Use the laser key to switch ON the laser.

Calibrating the height control, Nozzle centering

It is important that the height control gets calibrated after startup and any time you modify the machine setup. A precise calibrated machine produces higher cut quality and reduces collisions which will enhance the lifetime of your components.

Please refer to the respective sections in the Operation Manual.

  • Height Sensor Calibration.

  • Nozzle Centering.

Clear the error messages

Whenever there is a communication from PLC, the user can view the messages displayed in bottom left corner.

Switching the machine OFF

Please shut down the HMI before you switch OFF the system power supply to prevent a possible data loss.
