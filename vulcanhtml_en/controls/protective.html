Protective Glass Monitoring

Protective glass monitoring checks the condition of the protective glass to prevent low-quality parts and possible machine damage.

The behavior is defined as follows:

  • When the quality value of the protective glass drops below the error level during cutting, the machine stops processing, the beam turns off, and a window appears on the HMI.

  • When you click Close, the machine continues cutting the current sheet. Before processing the next sheet, it performs a protective glass measurement. If the quality is still below the error level, the window appears again. Each time you click Close, the machine continues processing, and the window reappears at the end of the sheet.

  • If the glass is contaminated from the start, the machine stops after cutting the first contour and performs a protective glass measurement. If the quality is below the error level, the window appears. Click Close to continue cutting the current sheet.

Triggers offline measurement

Offline measurement checks the glass quality under stable conditions. Three different laser power levels are emitted, each for a specific time period — typically 500 ms. The reflected light is measured at each power level, and the normalized reflection luminosity is calculated and compared with a reference value obtained using the same method. An offline broken factor is included in this calculation to determine the glass quality. For the same reflection luminosity value, a higher broken factor indicates better glass quality. Therefore, a warning or error is triggered only when the glass is significantly dirty.

Online monitoring checks the glass quality during cutting. Whenever there is laser output, the average value of the reflected light over a time period is calculated and a low-pass filter is applied. Due to the unstable nature of the laser output and back reflection from the cutting sheet, the online value is significantly higher than the offline value.

The measure mode provides two options:

  • Offline – Run the program and check the status of the protective glass.

  • Reference – Cross-verify the quality and linearity values and save them. Use this option for a new protective glass to obtain a reliable reference.
