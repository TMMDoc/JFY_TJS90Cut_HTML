Nanojoints

Nanojoints

Laser nanojoints are a type of advanced joining technology that utilizes laser beams to create a precise and strong connections which is reduced in depth. They speed up the process because it is so much faster to produce tiny retaining points rather than conventional micro tabs during cutting. They also allow the operator to break parts free from the nest with much less effort. This saves time and makes life easier for workers. In most cases, nano joints also completely eliminate the need for finishing work, since the mark they leave when the parts are broken free from the nest is barely visible. In contrast, microjoints leave much more obvious contour damage which subsequently has to be manually corrected by production staff.

To enable Nanojoint, navigate to Machine settings → PLC options → Laser Technology Miscellaneous Control.

The parametrization of the nanojoints is done in the laser tech table page.

The programming in LST format is done via the M-Command G824.

The programming in DIN format is done via the M-Command M1031.
