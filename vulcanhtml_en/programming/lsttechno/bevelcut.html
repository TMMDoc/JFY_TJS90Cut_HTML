Bevel cut

Bevel cut

The bevel cut function enables the manufacture of beveled cutting edges with an angle of 1° to 50° on the sheets. This enables the preparation of welding edges and the insertion of countersinks on the 2D laser machine.

The bevel cut function is only available for the TruLaser 3040/3060/3080.

TC_LASER_MACHINING_ON

Definition

The laser beam is ignited with the TC_LASER_MACHINING_ON cycle in the NC program.

Programming

TC_MACHINING_LASER_ON(laser method,"technology table",piercing type,cutting type)

  • Is programmed at the start of each contour machining.

Example

TC_LASER_MACHINING_ON(1,"ST030MD0-N2SB-30-2","PIERCE-10","BEVELCUT-100")

Parameter Value Description

Laser method

1

Piercing and cutting with distance regulation.

Technology table

ST030MD0-N2SB-30-2

Name of the laser technology table.

Piercing type

PIERCE-10

Normal piercing.

Cutting type

BEVELCUT-100

Bevel cutting large contour, normal cutting speed and normal acceleration.

TC_TRAFO_ON

Definition

The TC_TRAFO_ON cycle activates the axis transformation required for the bevel cut. This unlocks the locking unit of the rotary axis.

Programming

TC_TRAFO_ON

  • Self-holding (modal) operation.

  • Must be programmed before the TC_LASER_MACHINING_ ON cycle.

  • Is deleted by TC_TRAFO_OFF.

TC_TRAFO_OFF

Definition

The TC_TRAFO_OFF cycle deactivates the axis transformation and the bevel cut.

Programming

TC_TRAFO_OFF:

  • Self-holding (modal) operation.

  • Before doing so, switch off the laser with TC_LASER_OFF and position the cutting head vertically.

    • TC_TRANSFORMER_MODE(TM_VECTOR)

    • G01 X5 Y0 A3=0 B3=0 C3=1 T_ORI=0

TC_TRAFO_MODE

Definition

The TC_TRAFO_MODE cycle selects the interpolation method for the TC_TRAFO cycle. The orientation of the direction vector is specified by components A3, B3, C3 and that of the cone direction vector by components A6, B6, C6.

Programming

TC_TRAFO_MODE

  • Self-holding (modal) operation.

  • TC_TRAFO_MODE(TM_VECTOR) Vector interpolation.

  • TC_TRAFO_MODE(TM_CONE, TM_CLOCKWISE) Clockwise cone surface interpolation.

  • TC_TRAFO_MODE(TM_CONE, TM_COUNTERCLOCKWISE) Counter-clockwise cone surface interpolation.
