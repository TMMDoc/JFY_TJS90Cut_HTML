Overshoot height

TC_POS_LEVEL

Definition

Modifying the overtravel height.

The cutting head moves to the position of sheet surface plus overtravel height when the laser beam is switched off with TC_LASER_OFF(1) or (3).

Programming

TC_POS_LEVEL (Crossing height)

  • Self-holding (modal) operation.

  • Becomes effective with TC_LASER_OFF(1) or (3).

  • If TC_POS_LEVEL is not programmed, the Z axis approaches the standard

Parameter
Parameter Entry

Minimum overtravel height

0

The control system limits the minimum overtravel height to the current cutting height.

Maximum overtravel height

Basic setting (see data collection of the machine)

Between the minimum and maximum, any crossing height can be programmed in steps of 0.1 mm or 0.004 inches.

TC_POS_LEVEL_FIX

Definition

The TC_POS_LEVEL_FIX cycle defines in a cross-program manner how far the cutting head pulls back during cross over. Overshoot height

The cutting head moves to the position of sheet surface plus overtravel height when the laser beam is switched off with TC_LASER_OFF(1) or (3).

Programming

TC_POS_LEVEL_FIX(Overshoot height)

  • Self-holding (modal) operation.

  • Becomes effective with TC_LASER_OFF(1) or (3).

  • Overwrites TC_POS_LEVEL.

  • If TC_POS_LEVEL_FIX is not programmed, the Z axis at TC_LASER_OFF(1) approaches the values defined by TC_POS_LEVEL.

Basic setting (see data collection of the machine)

Between the minimum and maximum, any crossing height can be programmed in steps of 0.1 mm or 0.004 inches.
