Timing of parts

Timing of parts

TC_TIMER

Definition

With the TC_TIMER cycle, machining times for single workpieces can be measured, displayed, and logged. A maximum of five timings can be simultaneously programmed, and displayed together later.

Programming

TC_TIMER (INT P1, INT NUMBER, STRING[20] COMMENT)

  • The laser beam must not be ignited.

  • A maximum of five timings can be started parallel to each other, or one after the other. The sequence is arbitrary.

  • It takes 0.5 seconds to start each timing. If several timings are started simultaneously, then these 0.5 seconds are added to each timing.

  • The maximum measurable time is nine hours.

Parameter
Parameter Value Definition

INT P1

1

Start timing.

2

Stop timing, and save. At the same time, machining program continues to run.

3

Stop all timings, and display. The machining program will stop until the display is closed.

4

Stop all timings, and log. At the same time, machining program continues to run.

INT NUMBER

1 - 5

Number of the measurement.

STRING[20] COMMENT

-

Comment, no more than 20 characters.
Timing log

With TC_TIMER(4), the cycle writes the result of the measurements into the log 'tc_timer.txt'.

The log is written into the directory 'c:\dh\topsmanu.dir\log \tc_timer' and is formatted for evaluation via a table calculation. The log can be viewed and exported using the TC_TIMER Logs button under Programming, Additional functions.

  • The maximum size of the file is 100 kByte.

  • Once the maximum file size is reached, 20 % of the data at the beginning of the file (the oldest entries) are deleted.

  • The file can be completely deleted. It is then automatically re-created at the next measurement.

Log entry Definition

PROGRAMM

Name of the main program

DATE

Date and time of the log entry

TIMERNR

Number of the timer, transfer parameter INT_NUMBER

VALUE

Measured time in HH:MM:SS.

COMMENT

Comment, transfer parameter STRING[20] COMMENT
