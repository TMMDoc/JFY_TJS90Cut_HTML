TC_MICROJOINT

Microjoints/Nanojoints

Microjoints are microwebs that could usually be programmed only with the programming system TruTops. The microjoints defined in this way are permanently anchored in the NC program. They cannot be modified or deselected during the machining of parts at the machine.

Nanojoints specifically create small connections on the underside of the sheet between the cut part and the scrap skeleton. Nanojoint is only available for certain cutting processes and sheet thicknesses (see "Cutting data" in the data collection tables).

Depending on the machine, it may also be possible to program microjoints/nanojoints directly on the machine and select or deselect them as required. There are two different types of microjoints:

  • Programmed microjoints/nanojoints that are defined within the contour or at the end of the contour via G functions. The contour is marked here directly in the NC text for the part program.

  • Automatic microjoints/nanojoints that are always set at the end of the contour and defined without G functions. The definition is made here via the dimension of the contour in X- and Y-direction. The contour is not marked in the NC text.

The following points are valid:

  • Microjoints that can only be modified at the machine are only possible on the machine on surfaces of rectangular tubes or for plane processing.

  • The data for programmed microjoints is stored in a programspecific table. The data can be displayed and modified via the user interface of the control. This table can be used to activate and deactivate the microjoint types separately. The table is called up using the NC cycle TC_MICROJOINT ("table name").

  • The activation status of the microjoints in the table is stored with the program. In this way, an available program is guaranteed to be processed under the same conditions after every program change, even when fully automatic systems are used.

Definition

Call up table with microjoint data directly at the control system and activate or deactivate programmed- or automatic microjoints in the NC text.

The cycle TC_MICROJOINT in the NC program calls up the table containing all the parameters and the activation status of the functions. Data can be modified in the table. The modified table is updated automatically in the NC core.

Programming

TC_MICROJOINT("Table name"):

  • Self-holding (modal) operation.

  • Call up as early as possible before the required contour machining.

  • Is deselected using program end or with the selection of a new table.

G821

Definition

Defining programmable, contour related microjoints.

With this G function, the NC block within the contour is marked by setting a microjoint. The microjoint can be set within the contour or at the end of the contour.

If the microjoint is set within the contour, then piercing is automatically renewed.

Restrictions

Restrictions for microjoints within the contour:

  • Special forms of piercing, such as the "back-step", for example, are not supported. This is due to the approach procedure not being possible afterwards in the contour.

  • Approaching with reduced cutting parameters and subsequent switching to normal parameters is not possible.

Depending on the machine, special shapes are possible via the TC_LEAD_IN cycle (see "TC_LEAD_IN", pg. 5‐34).
Programming

G821:

The G821 function is assigned to a group of G commands. Only one G command may be used from this group within an NC block. The G commands belong to this group G820 – G829.

  • Is considered if programmed microjoints are activated or deactivated via the microjoint table.

  • Is not activated in the microjoint table as default. Standard: 0 = not activated; 1 = activated.

  • Is written into the contour’s NC block, at the end of which the microjoint is to be set.

  • Is immediately effective after activation if the laser cutting head within the positioning motion is located between two contours. If the laser cutting head is, however, found directly at the machining of a contour, then the function only becomes effective for the next contour machining.

  • Should the function be deactivated when a contour is being machined, then another microjoint will be set in this contour. The following contour is machined without a microjoint. If the machining head is found between two contours within a positioning motion, then the following contour will be machined without a microjoint.

G822

Definition

Skipping automatic microjoint in relation to the contour.

The criteria for an automatically set microjoint at the end of a contour is the dimension of the contour in X- and Y-direction. If the maximum dimension of the contour in X- or Y-direction lies within a range also defined in the microjoint table, then a microjoint is automatically set at the end of every contour.

Because the control system cannot differentiate between closed and open contours, every open contour must already be marked as such in the programming system. Otherwise, microjoints will also be set at open contours, i.e. these open contours will be shortened.

With G function G822, unwanted, automatic microjoints can now be skipped on the control.

Programming

G822:

The G822 function is allocated to a group of G commands. Only one G command may be used from this group within an NC block. The G commands belong to this group G820 – G829.

  • Is considered if automatic microjoints are activated or deactivated via the microjoint table. The table is called via TC_MICROJOINT ("table name").

  • Is not activated in the microjoint table as default. Standard: 0 = not activated; 1 = activated.

  • Can be written for the respective contour in a separate block or at the end of an NC block, but after TC_LASER_ON and before TC_LASER_OFF.

  • Is immediately effective after activation if the laser cutting head within the positioning motion is located between two contours. If the laser cutting head is, however, found directly at the machining of a contour, then the function only becomes effective for the next contour machining.

  • Should the function be deactivated when a contour is being machined, then another microjoint will be set in this contour. The following contour is machined without a microjoint. If the machining head is found between two contours within a positioning motion, then the following contour will be machined without a microjoint.

  • Is cleared with the next TC_LASER_OFF.

G824

Definition

Set programmable nanojoints.

Nanojoints hold the part only at the lower cutting area. This is achieved by reducing the laser power for a short time. Nanojoints are suitable for sophisticated parts, or if it should be possible to break parts out of the remainder sheet easily.

Programming

G824:

The G824 function is allocated to a group of G commands. Only one G command may be used from this group within an NC block. The G commands belong to this group G820 – G829.

  • It is taken into account if programmable nanojoints are activated or deactivated via the nanojoint table. The table is called via TC_MICROJOINT ("table name").

  • It is not activated in the nanojoint table by default. Standard: 0 = not activated; 1 = activated.

  • Can be written for the respective contour in a separate block or at the end of an NC block, but after TC_LASER_ON and before TC_LASER_OFF.

  • Is immediately effective after activation if the laser cutting head within the positioning motion is located between two contours. If the laser cutting head is, however, found directly at the machining of a contour, then the function only becomes effective for the next contour machining.

  • Should the function be deactivated when a contour is being processed, another nanojoint will be set in this contour. The following contour is processed without nanojoint. If the processing head is within a positioning motion between two contours, then the following contour will be processed without a nanojoint.

  • Is cleared with the next TC_LASER_OFF.

TC_LEAD_IN

Definition

With the TC_LEAD_IN cycle call-up in the NC program, technology parameters for the optimum approach strategy are selected after a microjoint.

The cycle is possible in the following machines:

  • TruLaser 1000 series

  • TruLaser Series 3000

  • TruLaser Series 5000

Programming

TC_LEAD_IN("Approach table", approach direction):

  • Approach table:

    • The tables contain all relevant information about parameters and methods of the approach procedure.

  • Approach direction:

    • Depending on the parameter setting, the programmed contour is approached to the left or right of the direction of machining.

    • TC_LEAD_IN ("Approach table", T_LEFT): Approaching the programmed contour on the left of the direction of movement.

    • TC_LEAD_IN ("Approach table", T_RIGHT): Approaching the programmed contour on the right of the direction of movement.

The parameter Approach direction marks the range for the finished part and scrap of a part.
