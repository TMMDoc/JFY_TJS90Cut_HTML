Laser Technology

Depends on the technology, the DIN program structure can be modified to suit the requirements of the user. Using the Laser Core 800 CNC controller, a DIN program for the Laser technology is composed of following:

  • Program Header

  • Technology Table Transfer

  • Check for Boundary program active

  • Block Jump

  • Block Number

  • Start of a Part Information

  • Laser parameters selection & Update

  • Contour statements

  • Program End

Example Program:

%1 (PP_Sample_Pgm.DIN)
CNC_ID=1
Sheet_Size_X = 120
Sheet_Size_Y = 600
Job_Size_X = 105
Job_Size_Y = 573
X_Limit_Minus = 10
X_Limit_Plus = 115
Y_Limit_Minus = 10
Y_Limit_Plus = 583
G17 D=SheetRotation

Program Header

G253 F="TT:MS_1mm" E0

Technology Table Transfer

CheckBoundPrg

Check for Boundary program active

G20 X1

Block Jump

N1
BlockNo=1 N1

Block Number

M01

Start of a part information if any

PM=20.000 CM=100.000
EM=1.000 ZRH=20
Update_Param

Laser parameters selection & Update

G61
Lead_In=4.374
G41 R=Kerf E0
G0 X57.018 Y461.5
M14 (Laser ON)
G1 X59.395 Y459.163
G3 X60.333 Y459.167 I0.467 J0.475
G3 I-2.828 J2.828
M15 (Laser OFF)
G40 E1

Contour Statements

G99
N65535 CallBoundPrg
